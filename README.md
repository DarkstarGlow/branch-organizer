# Branch Organizer

把长 AI 会话整理成可浏览、可修正、可导出的推进结构。

这是第一版实验性实现，目前包版本为 `0.0.1`。核心流程已在作者的实际会话中使用和验收，但不同会话的整理质量、分享页兼容性和长期使用效果仍需验证。欢迎试用、反馈问题和阅读代码。

## 能做什么

- 读取用户主动提供的 ChatGPT 公开分享链接，按每次用户提问划分 Step 时间线。
- 使用 DeepSeek 生成 Step 摘要和节点结构，浏览节点列表、结构图和原文。
- 手工修改节点、上下级关系和 Step 归属，保存到本地。
- 重新读取分享链接后恢复已有结构；对符合条件的尾部追加内容做增量整理。
- 选取节点，将原文、摘要和背景导出为 Markdown，供新的 AI 会话续接。
- 全量重新整理时先预览，确认后替换旧摘要和结构。

## 本地安装

需要 Node.js 22 或更高版本、npm 和 Chrome。下载或克隆本仓库，进入项目目录后运行：

```bash
npm ci
npm run build
```

打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择项目中的 `.output/chrome-mv3/` 目录。点击工具栏中的 Branch Organizer 图标，打开侧边栏。

目前通过本地构建安装；本说明不提供 Chrome 应用商店安装入口。

开发时运行：

```bash
npm run dev
```

WXT 通常会打开安装开发版插件的浏览器；如果自动启动失败，可按上面的方式手动加载构建产物。

## 基本使用

1. 在 ChatGPT 中创建公开分享链接，将 `https://chatgpt.com/share/…` 粘贴到插件。
2. 读取时间线，检查提问和回复是否完整。最后一段会标为 Tail。
3. 在插件中输入自己的 DeepSeek API Key，保存到本次浏览器会话，再生成探索结构。模型调用产生的费用由你的 DeepSeek API 账户承担。
4. 浏览或编辑节点，确认保存成功。之后重新读取同一链接，可在来源匹配时恢复结果。
5. 勾选要带走的节点，预览并复制或下载 Markdown，自行粘贴到新的 AI 会话。


## 使用模型

当前模型配置仅有 deepseek-flash

## 第一版的限制

- ChatGPT 分享页格式变化、访问验证或链接失效可能导致读取失败。
- Step 边界由程序决定，节点分组由模型提议；通过结构校验不代表语义整理一定正确。
- 历史中间改写不能自动合并；增量接续要求已有历史满足兼容条件。
- 恢复 AI 初始结构和采用全量重新整理结果会覆盖人工修改，没有撤销历史；重要内容请先导出。
- 本地记录没有云备份；卸载插件或清除扩展数据可能丢失记录。
- 原文以文本呈现，不还原 ChatGPT 页面中的交互组件；图片与附件内容不参与理解。
- 尚未系统验证所有会话类型和浏览器环境，不承诺生产服务可用性。

## 开发与检查

```bash
npm run compile   # TypeScript 类型检查
npm run build     # Chrome MV3 构建
npm run check     # 类型检查和构建
```

| 路径 | 职责 |
| --- | --- |
| `entrypoints/` | Background、侧边栏页面和交互 |
| `src/adapters/` | 分享页解析、模型接口、浏览器存储与导出 |
| `src/application/` | 摘要、结构生成、增量整理和导出流程 |
| `src/domain/` | Step、节点树、统一校验和纯业务规则 |

这个公开版本只包含运行源码与构建配置。直接运行依赖的许可原文见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
